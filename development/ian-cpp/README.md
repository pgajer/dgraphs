# IAN implementation and improvement

Start with [Project Aims](docs/project-aims.md), the [current roadmap](docs/roadmap.md)
and the [experiment catalogue](experiments/README.md). This maintained documentation
layer leaves development/ian-cpp-phase1 and private evidence unchanged. Stable question
identifiers complement historical phase aliases; this is not a package relocation.

Generated entry: [HTML catalogue](experiments/build/index.html). Printable companion:
[experiment book](experiments/build/experiment-book.pdf). Generated files are ignored,
not disposable; backup coverage remains explicitly unverified.

Source format is Markdown plus JSON-compatible YAML metadata (valid YAML 1.2).
The renderer does not load private audits or execute numerical analyses. New prose
and figures have author QA only until separately reviewed.
