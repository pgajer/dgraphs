# Shared methods and meanings

IAN builds an initial neighborhood graph, solves for local scales, retunes a
multiplier and removes edges through an adaptive history before final affinities.
A fixed linear program is one optimization problem inside that algorithm. Success
on fixed problems does not establish complete-trajectory or scientific validity.

## Reference conditions

Keep original-expression Python, evaluated-LP Python and native evaluated code
separate. Mathematical projection can agree while binary64 arithmetic or solver
paths differ. Clarabel QDLDL and HiGHS dual simplex are distinct algorithms; their
iteration counts are not equivalent units of work. Solver status, external numeric
certificates, scale agreement, graph decisions and final affinities are different
checks. The policy registry records which rules were used and whether adopted.

Ordinary external numerical limits are 1e-7 for the specified original-unit
primal/dual/objective checks. Scale comparisons use absolute plus relative limits;
consult each frozen contract for unit conversion. Exact objective-band membership
in the range study admits zero violation and cannot be replaced by a normalized
row tolerance. Exact repaired witnesses are distinct from raw solver returns.

## Denominators and reuse

A question record is not a phase, run, physical solver call, logical problem,
pruning step or profile. Failed attempts count as attempts. Synthetic guard events
are not optimization calls. Auditor reruns and repeated deterministic calls are
not independent biological observations. Shared inputs, overlapping subsets and
copied numerical evidence are explicitly linked rather than counted as replication.
No aggregate total of all project solver calls is claimed by this catalogue.

## Version and build boundaries

The evidence manifest identifies inputs/results/source references. The rendering
manifest identifies report and figure versions. A current source hash alone does
not prove a historical execution. Running an analysis, reconstructing a figure
from saved aggregate evidence and rendering a report are separate operations.
The catalogue scripts only perform the latter two, in separate commands.

Historical supervisor behavior is retained. New one-shot diagnostics use the
accepted reservation guard; it must not replace multi-solve protection without a
new budget design. Sampled resource limits are not hard operating-system quotas.
