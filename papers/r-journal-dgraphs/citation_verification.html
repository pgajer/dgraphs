dgraphsPackage
verified		 Introduction and availability: dgraphs supplies the graph constructors, lifecycle stages, diagnostics, and conversion described in the article. The version 0.2.0 source repository contains DESCRIPTION, exported documentation, vignettes, native sources, and tests for the stated software surface. gripPackage
verified		 Introduction and scope: the companion grip package assesses and refines coordinate representations of an already specified graph. The public package source documents graph-layout scoring and refinement, including comparison of graph-geodesic and coordinate-path distances. source Pawel Gajer (2026), grip 0.2.0, DOI 10.32614/CRAN.package.grip. Public CRAN availability is a pre-submission gate.
blusterPackage
verified		 Positioning: bluster builds kNN and shared-neighbor igraph objects for community detection, supports selectable BiocNeighbors backends, and exposes threaded construction. The makeKNNGraph() and makeSNNGraph() reference pages describe the igraph output, BNPARAM backend, num.threads argument, and downstream community-detection use. source Aaron Lun (2026), bluster 1.22.0, Bioconductor.

jarvisPatrick1973
verified		 Introduction: shared-nearest-neighbor graph ideas trace to Jarvis and Patrick. The paper defines similarity through overlap between k-nearest-neighbor lists, subject to mutual neighborhood membership. source Jarvis and Patrick (1973), IEEE Transactions on Computers C-22(11), 1025--1034.
brito1997
verified		 Introduction: mutual-kNN connectivity has been studied for clustering and outlier detection. verified		 Introduction: CkNN uses the geometric mean of local kNN scales and was introduced for density-adaptive manifold representation.
